# TEST CASES: 1. CONTAINER / PANEL / BOX

- **Mục đích:** Khung chứa định hình không gian và gom nhóm các phần tử có liên quan trên trang
- **Tổng số Test Case:** **8** (`High`: 4 | `Medium`: 2 | `Low`: 2)

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_CNT_001`** (High): Kiểm tra giao diện chuẩn của Container / Panel / Box (Max-width, căn giữa, Padding, Margin, Border & Shadow)
- [ ] **`TC_CNT_002`** (High): Kiểm tra khả năng đáp ứng bố cục (Responsive Grid / Flexbox) qua các kích thước màn hình
- [ ] **`TC_CNT_003`** (High): Kiểm tra tự động giãn chiều cao (`height: auto`) và xử lý tràn khung (Overflow) khi nội dung bên trong tăng đột biến
- [ ] **`TC_CNT_004`** (High): Kiểm tra không bị xô lệch bố cục (Layout Shift / Overlap) khi xuất hiện các phần tử động bên trong Box
- [ ] **`TC_CNT_005`** (Medium): Kiểm tra tính năng thu gọn/mở rộng Panel (Collapsible), phóng to toàn màn hình (Maximize) hoặc kéo vách ngăn (Resizable Split Pane)
- [ ] **`TC_CNT_006`** (Medium): Kiểm tra phân cấp màu nền (Surface Elevation) của Container và Box trên cả Light Mode và Dark Mode
- [ ] **`TC_CNT_007`** (Low): Kiểm tra bố cục Container khi phóng to/thu nhỏ trình duyệt (`Zoom 50% -> 200%`) và thẻ ngữ nghĩa HTML5
- [ ] **`TC_CNT_008`** (Low): Kiểm tra hiển thị các khối Container / Panel khi thực hiện In trang hoặc Xuất PDF (`Ctrl + P`)
