# TEST CASES: 6. EMPTY STATE

- **Mục đích:** Vùng hiển thị thông báo thân thiện khi chưa có dữ liệu (ví dụ: 'Chưa có đơn hàng nào')
- **Tổng số Test Case:** **6** (`High`: 4 | `Medium`: 2 | `Low`: 0)

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_EMP_001`** (High): Kiểm tra giao diện hiển thị chuẩn của vùng Empty State (Hình minh họa, Tiêu đề, Mô tả hướng dẫn và Nút CTA)
- [ ] **`TC_EMP_002`** (High): Kiểm tra phân biệt đúng thông điệp giữa 'Chưa có dữ liệu ban đầu' (Initial Empty) và 'Không tìm thấy kết quả' (No Search/Filter Results)
- [ ] **`TC_EMP_003`** (High): Kiểm tra hoạt động của nút hành động kêu gọi (CTA Button) trên màn hình Empty State
- [ ] **`TC_EMP_004`** (High): Kiểm tra tự động chuyển sang giao diện Empty State ngay sau khi xóa bản ghi cuối cùng trên danh sách
- [ ] **`TC_EMP_005`** (Medium): Kiểm tra không hiển thị nhầm Empty State khi API đang tải (Loading) hoặc khi API gặp lỗi (Error 500)
- [ ] **`TC_EMP_006`** (Medium): Kiểm tra hiển thị nút CTA trên Empty State theo phân quyền người dùng (Role Permission) và trên Mobile
