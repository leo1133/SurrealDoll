# TEST CASES: 4. LOADING SPINNER / PROGRESS BAR

- **Mục đích:** Vòng xoay hoặc thanh tiến trình thể hiện hệ thống đang xử lý dữ liệu hoặc tải tệp
- **Tổng số Test Case:** **7** (`High`: 5 | `Medium`: 1 | `Low`: 1)

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_PRG_001`** (High): Kiểm tra giao diện hiển thị, vị trí căn giữa và hiệu ứng chuyển động của Loading Spinner & Progress Bar
- [ ] **`TC_PRG_002`** (High): Kiểm tra kích hoạt Loading ngay khi bắt đầu gọi API và tự động ẩn ngay khi nhận kết quả
- [ ] **`TC_PRG_003`** (High): Kiểm tra độ chính xác của phần trăm tiến trình (`0% -> 100%`) trên Determinate Progress Bar
- [ ] **`TC_PRG_004`** (High): Kiểm tra khóa tương tác (Action Locking) trong khi đang Loading để chống gửi trùng lặp (Double Submit)
- [ ] **`TC_PRG_005`** (High): Kiểm tra xử lý tắt vòng xoay Loading (Chống lỗi Infinite Spinner) khi mất mạng, lỗi 500 hoặc Timeout
- [ ] **`TC_PRG_006`** (Medium): Kiểm tra chức năng Hủy tiến trình đang chạy (`Cancel` / `✕`) trên thanh Progress Bar
- [ ] **`TC_PRG_007`** (Low): Kiểm tra chống nháy màn hình (Flicker Delay) với tác vụ cực nhanh và thuộc tính hỗ trợ tiếp cận
