# TEST CASE: 4. PAGINATION

- **Mô tả chức năng:** Các nút phân trang và chuyển trang (First, Previous, 1, 2, 3, Next, Last, Page Size)
- **Tổng số Test Case:** **8** (`High: 7` | `Medium: 1` | `Low: 0`)
- **Phân bổ theo loại kiểm thử:** UI / Giao diện: **1**, Functional / Chức năng: **3**, Boundary / Giá trị biên: **2**, Validation & Negative: **2**

---

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_PAG_001`** [High] _UI / Giao diện_ — Kiểm tra giao diện hiển thị mặc định của thanh Phân trang (Pagination)
- [ ] **`TC_PAG_002`** [High] _Functional / Chức năng_ — Kiểm tra chuyển trang bằng số trang (1, 2, 3) và các nút Next (>), Previous (<), First (<<), Last (>>)
- [ ] **`TC_PAG_003`** [High] _Boundary / Giá trị biên_ — Kiểm tra trạng thái khóa (Disabled) của nút Previous/First tại Trang 1 và Next/Last tại Trang cuối
- [ ] **`TC_PAG_004`** [High] _Boundary / Giá trị biên_ — Kiểm tra tính toán số trang tại các giá trị biên của tổng số bản ghi (0, 10, 11 bản ghi với PageSize = 10)
- [ ] **`TC_PAG_005`** [High] _Functional / Chức năng_ — Kiểm tra thay đổi số dòng hiển thị trên mỗi trang (Page Size: 10 / 20 / 50 / 100)
- [ ] **`TC_PAG_006`** [High] _Functional / Chức năng_ — Kiểm tra tính đồng bộ khi kết hợp Phân trang với Tìm kiếm (Search), Bộ lọc (Filter) và Sắp xếp (Sort)
- [ ] **`TC_PAG_007`** [High] _Validation & Negative_ — Kiểm tra xử lý khi xóa bản ghi cuối cùng trên trang hiện tại (VD: xóa dòng duy nhất ở Trang 2)
- [ ] **`TC_PAG_008`** [Medium] _Validation & Negative_ — Kiểm tra rút gọn số trang (`1 2 ... 99 100`), ô 'Đi tới trang' và sửa tham số `?page=` trên URL
