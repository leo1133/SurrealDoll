# TEST CASE: 12. RICH TEXT EDITOR (WYSIWYG)

- **Mô tả chức năng:** Trình soạn thảo định dạng chữ (in đậm, nghiêng, chèn link, đổi màu...)
- **Tổng số Test Case:** **10** (`High: 8` | `Medium: 2` | `Low: 0`)
- **Phân bổ theo loại kiểm thử:** UI / Giao diện: **1**, Functional / Chức năng: **6**, Validation & Negative: **1**, Boundary / Giá trị biên: **1**, Security / Bảo mật: **1**

---

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_RTE_001`** [High] _UI / Giao diện_ — Kiểm tra giao diện thanh công cụ (Toolbar) và vùng soạn thảo của Rich Text Editor
- [ ] **`TC_RTE_002`** [High] _Functional / Chức năng_ — Kiểm tra các định dạng chữ cơ bản: In đậm (Bold), In nghiêng (Italic), Gạch chân (Underline), Gạch ngang (Strikethrough)
- [ ] **`TC_RTE_003`** [High] _Functional / Chức năng_ — Kiểm tra định dạng Kiểu tiêu đề (Heading H1-H6), Font chữ, Cỡ chữ, Màu chữ và Màu nền chữ
- [ ] **`TC_RTE_004`** [Medium] _Functional / Chức năng_ — Kiểm tra căn lề (Trái, Giữa, Phải, Đều 2 bên) và tạo danh sách (Bullet List, Numbered List)
- [ ] **`TC_RTE_005`** [High] _Functional / Chức năng_ — Kiểm tra chức năng Chèn / Sửa / Xóa liên kết (Hyperlink) và Hình ảnh / Bảng biểu
- [ ] **`TC_RTE_006`** [High] _Functional / Chức năng_ — Kiểm tra Copy & Paste nội dung có định dạng từ Word / Website ngoài và Paste as Plain Text
- [ ] **`TC_RTE_007`** [High] _Functional / Chức năng_ — Kiểm tra tính nhất quán giữa nội dung trong Editor và màn hình Hiển thị chi tiết (Preview / View Mode)
- [ ] **`TC_RTE_008`** [High] _Validation & Negative_ — Kiểm tra trường bắt buộc khi Editor chỉ chứa thẻ HTML rỗng (`<p><br></p>`) hoặc toàn dấu cách
- [ ] **`TC_RTE_009`** [Medium] _Boundary / Giá trị biên_ — Kiểm tra giới hạn số lượng ký tự tối đa (Maxlength) trong Rich Text Editor
- [ ] **`TC_RTE_010`** [High] _Security / Bảo mật_ — Kiểm tra bảo mật HTML Sanitization - Chống tấn công Stored XSS qua Rich Text Editor
