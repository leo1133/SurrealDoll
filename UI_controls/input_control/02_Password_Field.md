# TEST CASE: 2. PASSWORD FIELD

- **Mô tả chức năng:** Ô nhập mật khẩu có ẩn ký tự (`*****`) kèm icon xem/ẩn mật khẩu
- **Tổng số Test Case:** **10** (`High: 9` | `Medium: 0` | `Low: 1`)
- **Phân bổ theo loại kiểm thử:** UI / Giao diện: **1**, Functional / Chức năng: **1**, Validation & Negative: **4**, Boundary / Giá trị biên: **1**, Security / Bảo mật: **2**, Usability & Accessibility: **1**

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_PWD_001`** [High] _UI / Giao diện_ — Kiểm tra giao diện mặc định và ẩn ký tự (Masking) khi nhập mật khẩu
- [ ] **`TC_PWD_002`** [High] _Functional / Chức năng_ — Kiểm tra chức năng Xem / Ẩn mật khẩu (Click icon con mắt Show/Hide)
- [ ] **`TC_PWD_003`** [High] _Validation & Negative_ — Kiểm tra bỏ trống trường Password bắt buộc
- [ ] **`TC_PWD_004`** [High] _Boundary / Giá trị biên_ — Kiểm tra độ dài biên của mật khẩu (Minlength - 1, Minlength, Maxlength, Maxlength + 1)
- [ ] **`TC_PWD_005`** [High] _Validation & Negative_ — Kiểm tra quy tắc độ mạnh mật khẩu (Password Complexity Policy)
- [ ] **`TC_PWD_006`** [High] _Validation & Negative_ — Kiểm tra xử lý khoảng trắng (Space) và ký tự tiếng Việt có dấu trong mật khẩu
- [ ] **`TC_PWD_007`** [High] _Validation & Negative_ — Kiểm tra đối chiếu với ô Xác nhận mật khẩu (Confirm Password)
- [ ] **`TC_PWD_008`** [High] _Security / Bảo mật_ — Kiểm tra chặn Copy / Cut mật khẩu từ ô Password Field
