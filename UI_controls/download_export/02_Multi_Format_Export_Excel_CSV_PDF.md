# TEST CASE: 2. MULTI-FORMAT EXPORT CONTROL (XUẤT DỮ LIỆU EXCEL, CSV, PDF)

- **Mục đích:** Nút bấm hoặc Dropdown cho phép xuất danh sách dữ liệu / báo cáo ra các định dạng chuẩn (.xlsx, .csv, .pdf, .json)
- **Tổng số kịch bản:** **7 Test Cases** (`High: 5`, `Medium: 1`, `Low: 1`)

---

## I. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_EXP_001`** ([High] - *UI & Functional*): Kiểm tra menu chọn định dạng xuất dữ liệu (Excel .xlsx, CSV .csv, PDF .pdf) và quy tắc đặt tên file tự động
- [ ] **`TC_EXP_002`** ([High] - *Functional / Chức năng*): Kiểm tra độ chính xác 100% của dữ liệu trong file Excel (.xlsx) so với bảng hiển thị trên màn hình UI
- [ ] **`TC_EXP_003`** ([High] - *Functional / Chức năng*): Kiểm tra không bị lỗi font chữ Tiếng Việt (UTF-8 with BOM) khi xuất file .CSV và mở bằng Microsoft Excel
- [ ] **`TC_EXP_004`** ([High] - *Boundary & Validation*): Kiểm tra giữ nguyên số 0 ở đầu Số điện thoại/Mã ZIP, định dạng Ngày tháng, Tiền tệ và số dài (> 15 chữ số) trong Excel/CSV
- [ ] **`TC_EXP_005`** ([Medium] - *Functional / Chức năng*): Kiểm tra chất lượng bố cục và ngắt trang khi xuất báo cáo ra định dạng PDF (.pdf)
- [ ] **`TC_EXP_006`** ([High] - *Validation & Security*): Kiểm tra bảo mật chống lỗ hổng CSV / Excel Formula Injection khi dữ liệu bắt đầu bằng dấu =, +, -, @
- [ ] **`TC_EXP_007`** ([Low] - *Functional / Chức năng*): Kiểm tra độ rộng cột tự động căn chỉnh (Auto-fit Column Width) trong file Excel xuất ra
