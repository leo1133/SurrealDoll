# TEST CASE: 1. DIRECT DOWNLOAD BUTTON & FILE ATTACHMENT (NÚT TẢI XUỐNG TRỰC TIẾP)

- **Mục đích:** Nút bấm hoặc liên kết tải xuống trực tiếp tệp tin đính kèm, tài liệu mẫu (Template), hóa đơn, hợp đồng (.pdf, .docx, .xlsx, .zip)
- **Tổng số kịch bản:** **6 Test Cases** (`High: 5`, `Medium: 1`, `Low: 0`)

---

## I. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_DL_001`** ([High] - *UI / Giao diện*): Kiểm tra giao diện nút Tải xuống (Download Button) và thông tin tệp đính kèm (Icon, Tên file, Định dạng, Dung lượng)
- [ ] **`TC_DL_002`** ([High] - *Functional / Chức năng*): Kiểm tra tải xuống thành công tệp tin, đúng tên file, đúng định dạng và mở file không bị lỗi hỏng (Corrupted)
- [ ] **`TC_DL_003`** ([High] - *Functional / Chức năng*): Kiểm tra trạng thái Loading / Disabled trên nút khi đang tải và chống bấm đúp (Spam Click) tải trùng nhiều lần
- [ ] **`TC_DL_004`** ([Medium] - *Functional / Chức năng*): Kiểm tra tính năng 'Tải xuống tất cả (Download All as .ZIP)' khi bản ghi có nhiều tệp đính kèm
- [ ] **`TC_DL_005`** ([High] - *Validation & Negative*): Kiểm tra xử lý lỗi khi tệp không tồn tại trên Server (404), lỗi hệ thống (500) hoặc mất mạng khi bấm tải
- [ ] **`TC_DL_006`** ([High] - *Validation & Security*): Kiểm tra bảo mật phân quyền khi tải tệp nhạy cảm (Chặn truy cập trái phép 401/403 hoặc Signed URL hết hạn)
