# TEST CASES: 5. TAG INPUT / MENTION (@)

- **Mục đích:** Ô nhập cho phép tạo các thẻ (Chip/Tag) khi nhấn Enter/dấu phẩy và gợi ý người dùng khi gõ ký tự @
- **Tổng số Test Case:** **7** (`High`: 5 | `Medium`: 2 | `Low`: 0)

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_TAG_001`** (High): Kiểm tra tạo thẻ Tag (Chip) mới khi gõ văn bản và nhấn phím `Enter` hoặc dấu phẩy `,`
- [ ] **`TC_TAG_002`** (High): Kiểm tra xóa thẻ Tag bằng nút `✕` trên từng Chip hoặc nhấn phím `Backspace` trên bàn phím
- [ ] **`TC_TAG_003`** (High): Kiểm tra chặn tạo Tag rỗng (chỉ chứa khoảng trắng), chặn Tag trùng lặp và giới hạn số lượng Tag tối đa
- [ ] **`TC_TAG_004`** (High): Kiểm tra tính năng nhắc tên `@Mention`: Mở danh sách gợi ý khi gõ `@`, lọc theo từ khóa và chọn bằng Enter/Click
- [ ] **`TC_TAG_005`** (Medium): Kiểm tra không kích hoạt nhầm Popup `@Mention` khi người dùng đang gõ địa chỉ Email
- [ ] **`TC_TAG_006`** (Medium): Kiểm tra dán (`Paste`) chuỗi nhiều từ khóa ngăn cách bởi dấu phẩy để tự động tách thành nhiều Tags
- [ ] **`TC_TAG_007`** (High): Kiểm tra chống thực thi mã độc XSS khi tạo thẻ Tag hoặc tìm kiếm `@Mention` bằng chuỗi HTML
