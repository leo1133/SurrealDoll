# TEST CASE: 4. COMMAND PALETTE (CTRL + K / CMD + K)

- **Mục đích:** Hộp tìm kiếm toàn cục và gọi lệnh nhanh bằng bàn phím (Spotlight / Command Bar)
- **Tổng số kịch bản:** **7 Test Cases** (`High: 4`, `Medium: 3`, `Low: 0`)

---

## I. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_CMD_001`** ([High] - *UI & Functional*): Kiểm tra mở nhanh hộp Command Palette từ bất kỳ màn hình nào bằng phím tắt Ctrl + K / Cmd + K và Auto-focus
- [ ] **`TC_CMD_002`** ([High] - *Functional / Chức năng*): Kiểm tra tìm kiếm tức thì (Instant / Fuzzy Search), phân nhóm kết quả và tô đậm từ khóa khớp
- [ ] **`TC_CMD_003`** ([High] - *Functional / Chức năng*): Kiểm tra điều hướng hoàn toàn bằng bàn phím (Mũi tên Lên/Xuống, Enter thực thi lệnh và Esc đóng hộp)
- [ ] **`TC_CMD_004`** ([Medium] - *Functional / Chức năng*): Kiểm tra hiển thị 'Lệnh vừa dùng gần đây (Recent)' và truy cập lệnh con đa cấp (Nested Commands)
- [ ] **`TC_CMD_005`** ([Medium] - *Boundary & Validation*): Kiểm tra trạng thái không tìm thấy lệnh nào (Empty State) và xử lý ký tự đặc biệt trong Command Palette
- [ ] **`TC_CMD_006`** ([High] - *Validation & Negative*): Kiểm tra phân quyền bảo mật: Không hiển thị các lệnh / trang Quản trị mà tài khoản không có quyền truy cập
- [ ] **`TC_CMD_007`** ([Medium] - *Validation & Negative*): Kiểm tra nhấn Ctrl + K lặp lại để đóng/mở (Toggle) và khôi phục vị trí Focus sau khi đóng Command Palette
