# TEST CASE: 2. CONTEXT MENU (MENU CHUỘT PHẢI / NHẤN GIỮ)

- **Mục đích:** Menu ngữ cảnh bật ra tại vị trí con trỏ khi Click chuột phải (trên Web) hoặc Nhấn giữ / Long-press (trên Mobile)
- **Tổng số kịch bản:** **6 Test Cases** (`High: 4`, `Medium: 1`, `Low: 1`)

---

## I. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_CTX_001`** ([High] - *UI & Functional*): Kiểm tra bật Context Menu đúng tại tọa độ con trỏ khi Click chuột phải và chặn menu mặc định của trình duyệt
- [ ] **`TC_CTX_002`** ([High] - *Functional / Chức năng*): Kiểm tra thực thi lệnh trên Context Menu, trạng thái mục bị vô hiệu hóa (Disabled) và mở nhánh menu con (Sub-menu)
- [ ] **`TC_CTX_003`** ([High] - *Boundary / Giá trị biên*): Kiểm tra tự động căn chỉnh vị trí Context Menu và Sub-menu khi Click chuột phải ở sát góc dưới bên phải màn hình
- [ ] **`TC_CTX_004`** ([High] - *Functional / Chức năng*): Kiểm tra đóng Context Menu khi Click trái ra ngoài, nhấn Esc, cuộn trang hoặc Click phải sang đối tượng khác
- [ ] **`TC_CTX_005`** ([Medium] - *Functional / Chức năng*): Kiểm tra mở Context Menu bằng cử chỉ Nhấn giữ (Long-press ~500ms) trên thiết bị cảm ứng Mobile / Tablet
- [ ] **`TC_CTX_006`** ([Low] - *Usability & Accessibility*): Kiểm tra mở và điều hướng Context Menu bằng bàn phím (Shift + F10 / Phím Menu, mũi tên Lên/Xuống, Enter)
