# TEST CASE: 1. PRIMARY BUTTON

- **Mô tả chức năng:** Nút hành động chính trên màn hình (Lưu, Đăng nhập, Mua ngay, Thanh toán...)
- **Tổng số Test Case:** **9** (`High: 6` | `Medium: 3` | `Low: 0`)
- **Phân bổ theo loại kiểm thử:** UI / Giao diện: **3**, Functional / Chức năng: **1**, Boundary / Giá trị biên: **2**, Validation & Negative: **1**, Usability & Accessibility: **1**, Security / Bảo mật: **1**

---

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_PRI_001`** [High] _UI / Giao diện_ — Kiểm tra giao diện hiển thị mặc định của nút hành động chính (Primary Button)
- [ ] **`TC_PRI_002`** [Medium] _UI / Giao diện_ — Kiểm tra hiệu ứng tương tác Hover, Active (Pressed) và Focus trên Primary Button
- [ ] **`TC_PRI_003`** [High] _Functional / Chức năng_ — Kiểm tra kích hoạt thành công hành động chính khi click Primary Button
- [ ] **`TC_PRI_004`** [High] _Boundary / Giá trị biên_ — Kiểm tra chống Double Click / Spam Click liên tục (Loading State & Idempotency)
- [ ] **`TC_PRI_005`** [High] _Validation & Negative_ — Kiểm tra khôi phục trạng thái nút khi API trả về lỗi hoặc mất kết nối mạng
- [ ] **`TC_PRI_006`** [High] _UI / Giao diện_ — Kiểm tra trạng thái Disabled của Primary Button
- [ ] **`TC_PRI_007`** [Medium] _Boundary / Giá trị biên_ — Kiểm tra hiển thị khi nhãn nút (Label) dài hoặc chuyển đổi đa ngôn ngữ (VI / EN)
- [ ] **`TC_PRI_008`** [Medium] _Usability & Accessibility_ — Kiểm tra kích hoạt Primary Button bằng bàn phím (Tab + Enter / Space)
- [ ] **`TC_PRI_009`** [High] _Security / Bảo mật_ — Kiểm tra bảo mật phân quyền khi người dùng cố tình xóa thuộc tính 'disabled' qua DevTools
