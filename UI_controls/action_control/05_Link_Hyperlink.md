# TEST CASE: 5. LINK / HYPERLINK

- **Mô tả chức năng:** Đường dẫn điều hướng nội bộ hệ thống hoặc dẫn ra website bên ngoài
- **Tổng số Test Case:** **8** (`High: 4` | `Medium: 4` | `Low: 0`)
- **Phân bổ theo loại kiểm thử:** UI / Giao diện: **1**, Functional / Chức năng: **3**, Security / Bảo mật: **1**, Usability & Accessibility: **2**, Boundary / Giá trị biên: **1**

---

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_LNK_001`** [High] _UI / Giao diện_ — Kiểm tra giao diện nhận diện và các trạng thái Hover, Active, Visited của Hyperlink
- [ ] **`TC_LNK_002`** [High] _Functional / Chức năng_ — Kiểm tra điều hướng đối với Liên kết nội bộ (Internal Link) và không có Broken Link (404)
- [ ] **`TC_LNK_003`** [High] _Functional / Chức năng_ — Kiểm tra điều hướng đối với Liên kết ra website bên ngoài (External Link mở Tab mới)
- [ ] **`TC_LNK_004`** [High] _Security / Bảo mật_ — Kiểm tra bảo mật chống Reverse Tabnabbing (`rel="noopener noreferrer"`) và giao thức độc hại
- [ ] **`TC_LNK_005`** [Medium] _Usability & Accessibility_ — Kiểm tra mở Link bằng Chuột giữa (Middle-click), Ctrl/Cmd + Click và Menu chuột phải
- [ ] **`TC_LNK_006`** [Medium] _Functional / Chức năng_ — Kiểm tra các loại liên kết đặc biệt: Anchor Link (`#id`), Email (`mailto:`), Điện thoại (`tel:`) và Tải file
- [ ] **`TC_LNK_007`** [Medium] _Boundary / Giá trị biên_ — Kiểm tra hiển thị khi văn bản đường dẫn (URL Text) quá dài trên khung hẹp / Mobile
- [ ] **`TC_LNK_008`** [Medium] _Usability & Accessibility_ — Kiểm tra điều hướng bằng phím Tab và kích hoạt Link bằng phím Enter
