# TEST CASE: 4. ICON BUTTON

- **Mô tả chức năng:** Nút chỉ có biểu tượng icon không có chữ (Thùng rác 🗑 xóa, Bút ✏️ sửa, Đóng ✕...)
- **Tổng số Test Case:** **8** (`High: 4` | `Medium: 4` | `Low: 0`)
- **Phân bổ theo loại kiểm thử:** UI / Giao diện: **3**, Usability & Accessibility: **2**, Functional / Chức năng: **2**, Validation & Negative: **1**

---

## 1. Checklist Kiểm Thử Nhanh (Quick QA Checklist)

- [ ] **`TC_ICN_001`** [High] _UI / Giao diện_ — Kiểm tra giao diện hiển thị, độ sắc nét và căn chỉnh của các nút Icon Button
- [ ] **`TC_ICN_002`** [High] _Usability & Accessibility_ — Kiểm tra hiển thị Tooltip giải thích chức năng khi di chuột (Hover) vào Icon Button
- [ ] **`TC_ICN_003`** [Medium] _UI / Giao diện_ — Kiểm tra diện tích vùng nhận click/chạm (Hit Area / Touch Target) của Icon Button
- [ ] **`TC_ICN_004`** [High] _Functional / Chức năng_ — Kiểm tra thực thi đúng chức năng của từng Icon Button trên danh sách dữ liệu
- [ ] **`TC_ICN_005`** [High] _Validation & Negative_ — Kiểm tra hộp thoại xác nhận an toàn khi click Icon Button mang tính xóa/phá hủy (Thùng rác 🗑)
- [ ] **`TC_ICN_006`** [Medium] _Functional / Chức năng_ — Kiểm tra nhóm Toggle Icon Button (Nút icon bật/tắt 2 trạng thái: Yêu thích ❤️, Đánh dấu ⭐, Ghim 📌)
- [ ] **`TC_ICN_007`** [Medium] _UI / Giao diện_ — Kiểm tra trạng thái Loading và Disabled của Icon Button
- [ ] **`TC_ICN_008`** [Medium] _Usability & Accessibility_ — Kiểm tra thuộc tính trợ năng (aria-label) và điều khiển bằng bàn phím cho Icon Button
