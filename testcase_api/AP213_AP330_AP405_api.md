## 2. MA TRẬN VIEWPOINTS THEO `API_controls/API_Viewpoint.md`

- **Header & Authentication:** `HDR-001`, `ACC-001`, `CT-003`, `AUTH-001` (Thiếu Token), `AUTH-003` (Token hết hạn), `AUTH-006` (Token sai chữ ký).
- **Authorization & RBAC:** `PERM-001` (Role Master Admin), `PERM-002` (Role Agency truy cập trái phép), `PERM-008` (User ID không sở hữu model).
- **Path Parameters Validation:** `PATH-001` (model_id không tồn tại), `PATH-002` (sub_model_id sai quan hệ cha-con), `PATH-003` (model_type không hợp lệ).
- **JSON Payload Validation:** `BODY-001` (Rỗng), `BODY-004` (Sai schema), `BODY-008` (Thiếu trường bắt buộc), `INT-001`, `FLT-001`, `FLT-006` (Số âm), `FLT-010` (Boundary Min/Max).
- **Business Logic & CSDL (Trụ Cột 7):**
  - **L1 (Persistence):** Gọi POST Save $\rightarrow$ Gọi GET verify lại dữ liệu lưu trong DB Postgres JSONB.
  - **L2 (Exclusion):** Chặn model đã bị soft-delete (`is_deleted = true`), chặn gán phụ kiện sai layer cha.
  - **L3 (Boundary):** Min $\le$ Max, Step $> 0$, Sensitivity $\ge 0$.
  - **L4 (Idempotency):** Spam click Save không tạo duplicate bản ghi setting.
  - **L5 (E2E Integration):** Admin Save tham số $\rightarrow$ User GET parameters nhận đúng giá trị mới.
- **Security:** `SEC-001` (SQL Injection payload), `SEC-002` (XSS trong field text), `SEC-010` (Parameter Tampering).
