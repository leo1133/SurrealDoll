## 1. BÓC TÁCH THÔNG TIN CONTRACT API (API CONTRACT ANALYSIS)

| Thuộc tính Contract | Chi tiết Đặc tả Kỹ thuật |
| :--- | :--- |
| **Danh mục Endpoint** | 1. `GET /agency/{agency_id}/` (Lấy chi tiết hồ sơ Agency)<br>2. `PATCH /agency/{agency_id}/` (Cập nhật từng phần thông tin Agency)<br>3. `POST /agency/auth/verify-email-change/` (Xác thực token mail PEM4 hoàn tất đổi email Owner)<br>4. `DELETE /agency/{agency_id}/` (Xóa mềm Agency & giải phóng Liver) |
| **Base URL (Dev / STG)** | `https://api-admin-dev.surrealdolls.com` / `https://api-admin-stg.surrealdolls.com` |
| **Tài liệu Swagger** | [Swagger Agency Manager](https://api-admin-dev.surrealdolls.com/docs#/Agency%20Manager) |
| **Postman Collection** | `agency/{agency_id}/Get Agency By Id`, `Update Agency`, `Delete Agency`, `auth/verify-email-change` |
| **Headers bắt buộc** | `Authorization: Bearer <master_admin_token>`<br>`Content-Type: application/json` (cho PATCH và POST verify)<br>`Accept: application/json` |
| **Phân quyền RBAC** | Master Admin (`マスター`). Agency Admin chỉ được xem thông tin chính Agency của mình; không được xóa/sửa trái phép (403 Forbidden). |
| **Cơ chế Idempotent** | GET: Idempotent. PATCH: Non-idempotent. DELETE: Idempotent (Lần 1: 200/204; Lần 2: 404 theo giả định A12). |

## 2. MA TRẬN 419 VIEWPOINTS ĐÃ PHỦ THEO `API_controls/API_Viewpoint.md`

- **Path Parameter (`agency_id`):** `PATH-001`, `PATH-002`, `PATH-003`, `PATH-004`, `PATH-005`, `PATH-006`, `PATH-007`, `PATH-008`, `PATH-010`, `PATH-011`, `PATH-012`.
- **Header & Auth:** `HDR-001`, `ACC-001`, `CT-001`, `CT-003`, `AUTH-001`, `AUTH-007`, `AUTH-009`, `AUTH-013`, `AUTH-015`.
- **RBAC & IDOR Permission:** `PERM-001`, `PERM-002`, `PERM-003`, `PERM-004`, `PERM-005`.
- **CRUD Update (`PATCH`):** `UPD-001`, `UPD-002`, `UPD-003`, `UPD-004`, `UPD-005`, `UPD-006`, `UPD-007`, `UPD-008`, `UPD-009`, `UPD-010`, `UPD-011`, `UPD-012`, `UPD-013`, `UPD-014`.
- **CRUD Delete (`DELETE`):** `DEL-001`, `DEL-002`, `DEL-003`, `DEL-004`, `DEL-005`, `DEL-006`, `DEL-007`, `DEL-008`.
- **Email Change 2-Step Flow (CR 19/10/2026):** `MAIL-001`–`015`, trường `pending_email`, mail `PEM4`, endpoint `POST /agency/auth/verify-email-change/`.
- **Password Reset & Session Revocation (CR 21/10/2026):** CMR43, kiểm tra trùng 3 lần gần nhất (`MSG261`), thu hồi session token (`AUTH-013`).
- **Release Liver Logic:** Chuyển `status: 2` hoặc `DELETE` tự động hủy liên kết Liver (`agency_id = null`), khóa tài khoản Agency Admin.
- **Response Validation & Security:** `RESP-001`, `RESP-002`, `RESP-010`, `RESP-015`, `SEC-001`, `SEC-004`, `NFR-001`.
